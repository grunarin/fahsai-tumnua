# 🌶️ ร้านฟ้าใสตำนัว: ระบบสั่งอาหารโต๊ะผ่าน QR Code & วางแผนเตรียมวัตถุดิบ (Smart POS)

ระบบบริหารจัดการร้านอาหารอีสาน **"ฟ้าใสตำนัว"** ส้มตำ ยำ ลาบ ย่าง ต้มแซ่บ พัฒนาด้วย **Python (Flask)** เชื่อมโยงกับหน้าเว็บ **HTML5 + Tailwind CSS** ที่สวยงามทันสมัย รองรับการสั่งอาหารผ่าน QR Code แบบ Real-time จอครัวเคาน์เตอร์คิดเงิน และระบบรายงานวิเคราะห์ยอดขายเพื่อวางแผนเตรียมอาหารล่วงหน้า

---

## ✨ ฟังก์ชันเด่นของระบบ "ฟ้าใสตำนัว"

### 1. 📱 ลูกค้าสแกนสั่งอาหารผ่าน QR Code ประจำโต๊ะ
- ลูกค้าสแกน QR Code ประจำโต๊ะเพื่อเปิดเมนูอาหารอีสานแซ่บๆ สั่งได้ทันที ไม่ต้องดาวน์โหลดแอป
- เมนูจัดเป็นหมวดหมู่ชัดเจน:
  - **ส้มตำ & ตำนัว:** ตำปูปลาร้านัวแซ่บ, ตำไทยไข่เค็ม, ตำข้าวโพดกุ้งสด, ตำถาดฟ้าใสรวมมิตร
  - **ย่าง & ทอด & ลาบ:** คอหมูย่างฉ่ำซอสน้ำจิ้มแจ่ว, ไก่ย่างสมุนไพรเขาสวนกวาง, ลาบหมูสับตับหวานข้าวคั่ว, ปีกไก่ทอดน้ำปลา
  - **ต้ม & ซดร้อน:** ต้มแซ่บกระดูกอ่อนหมูใบกะเพรา
  - **ข้าว & เครื่องเคียง:** ข้าวเหนียวเขี้ยวงูอบนุ่ม, ขนมจีนแป้งหมัก, แคบหมูไร้มัน
  - **เครื่องดื่ม & ของหวาน:** ชาไทยเย็นสูตรโบราณ, น้ำเก๊กฮวยต้มสมุนไพร, ลอดช่องสิงคโปร์กะทิสด
- เลือกระดับความเผ็ดและใส่โน้ตพิเศษได้ตามชอบ (*เผ็ดน้อย, ไม่ใส่พริก, เปรี้ยวหวาน, ปลาร้าสุก*)
- ตะกร้าอาหารคำนวณยอดเงินอัตโนมัติ
- ติดตามสถานะออเดอร์แบบ Real-time (*รอร้านรับ ➔ ครัวกำลังปรุง ➔ เสิร์ฟแล้ว ➔ คิดเงิน*)

### 2. 👨‍🍳 จอจัดการเคาน์เตอร์และห้องครัว (Counter & Kitchen POS)
- รายการอาหารที่ลูกค้าสั่งจากโต๊ะเด้งเข้าจอทันที พร้อมเสียงกระดิ่งเตือน (Chime)
- ปุ่มเปลี่ยนสถานะ 4 สเต็ป:
  1. `[ 1. กดรับออเดอร์ ]` ⏳ ➔ เปลี่ยนเป็น **ครัวกำลังปรุง**
  2. `[ 2. ทำอาหารเสร็จ ]` 🍳 ➔ เปลี่ยนเป็น **ปรุงเสร็จ รอเสิร์ฟ**
  3. `[ 3. นำเสิร์ฟแล้ว ]` 🍲 ➔ เปลี่ยนเป็น **เสิร์ฟแล้ว**
  4. `[ 4. รับเงินค่าอาหาร (ปิดบิล) ]` 🍽️ ➔ บันทึกยอดขายและปิดโต๊ะ
- ปุ่ม **"เช็คบิลโต๊ะ"** รวมยอดทุกออเดอร์ของโต๊ะนั้นและปิดการขายในคลิกเดียว

### 3. 📊 รายงานยอดขายรายวัน & วางแผนเตรียมของ (Food Prep Planner)
- **สรุปตัวเลขทางการเงิน:** ยอดขายรวมสุทธิ, ต้นทุนรวม, กำไรขั้นต้น (Gross Profit), อัตรากำไร %, จำนวนบิล, ยอดเฉลี่ยต่อโต๊ะ
- **กราฟช่วงเวลาขายดี (Hourly Peak Hours):** วิเคราะห์ชั่วโมงเร่งด่วนมื้อเที่ยงและมื้อเย็น เพื่อจัดกะพนักงานและเตรียมเตาย่าง/ครกตำ
- **กราฟแนวโน้มยอดขายย้อนหลัง 7 วัน (7-Day Trend)**
- **ตารางวางแผนเตรียมวัตถุดิบ (Food Prep Planner):** 
  - คำนวณปริมาณ *เส้นมะละกอ, น้ำปลาร้า, คอหมูสด, ไก่สด, ข้าวเหนียว, มะนาว* ที่ใช้จริงในแต่ละวัน
  - **แนะนำสต็อกล่วงหน้า (+15% Buffer):** คำนวณปริมาณที่ควรหั่น/หมัก/หุง สำหรับวันถัดไป ป้องกันของขาดช่วงลูกค้าแน่น
  - มีคำแนะนำขั้นตอนการเตรียมสำหรับแม่ครัวและเชฟ
- ปุ่มพิมพ์ใบเตรียมของให้ครัว (Print A4) และปุ่มดาวน์โหลดไฟล์ Excel/CSV

## 🛠️ โครงสร้างไฟล์ในโปรเจกต์

```text
restaurant_system/
├── app.py                  # ตัวเซิร์ฟเวอร์หลัก Python Flask & REST APIs (ร้านฟ้าใสตำนัว)
├── restaurant.db           # ฐานข้อมูล SQLite (เมนู, สูตร, ออเดอร์, ยอดขาย)
├── requirements.txt        # รายการแพ็กเกจ Python (Flask, Gunicorn)
├── Procfile                # ไฟล์ตั้งค่าสำหรับ Deploy บน Cloud (Render/Railway)
├── .gitignore              # ไฟล์ยกเว้นไฟล์ที่ไม่จำเป็นในการขึ้น Git
└── templates/              # หน้าตา UI (HTML + Tailwind CSS)
    ├── home.html           # หน้าหลัก Hub & QR Code Generator
    ├── table.html          # หน้าสั่งอาหารสำหรับลูกค้าบนมือถือ (โต๊ะ 1 - 6)
    ├── counter.html        # หน้าจอเคาน์เตอร์และครัว
    └── reports.html        # หน้ารายงานการขาย & วางแผนเตรียมวัตถุดิบ
```

## 🚀 วิธีเปิดใช้งานบนเครื่อง (Localhost)

1. เปิด Terminal / PowerShell ไปที่โฟลเดอร์โปรเจกต์:
```bash
cd c:\Users\ADVS\Documents\chatGPT_img\restaurant_system
```
2. ติดตั้ง Library (หากยังไม่ได้ติดตั้ง):
```bash
pip install -r requirements.txt
```
3. เริ่มต้นรันเซิร์ฟเวอร์:
```bash
python app.py
```
